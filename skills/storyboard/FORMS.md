# Forms

Use these forms as ideas, not as templates. Always add one form that is not in this list. Compare it with the best catalogue form. Keep the form with the clearer final frame.

## Rules to select and test a form

1. Write the result as one sentence: "AND ..., BUT ..., THEREFORE ...". If you cannot, do not draw.
2. Make the final frame first. Then select the form that leads to it.
3. Find the one comparison that carries the result. Keep the same position and scale on both sides.
4. Make the result readable with the sound off. Use one caption word or one HUD value.
5. Give the viewer a stake before the result: a guess, a character, or a risk. Show the wrong idea, then break it.
6. Build the set once and tell the story inside it. The viewer learns a composition once; each new set costs that time again.

## Inside the set

- **Memory.** A character that dies stays as a shadow to the end of the set. Marks stay on the body. A shadow is drawn by the set (a custom scene), not by an actor: in the plan, a destroyed actor does not come back.
- **A detail as a metaphor.** One object carries the idea: a scan with a spot, spots on a body, a case folder.
- **Life.** Cells look for a target, run, and divide. A character at rest moves a little; it does not stand still.

## Catalogue

Set: what stays on screen for the whole video. What changes: what comes and goes inside it. A ready scene is a scene type of `animate` (PLAN.md): when one shows a set, the Set cell names it (`ready: <type>`).

| Form | Fits | Set | What changes | Example |
|---|---|---|---|---|
| Levels | An experiment with 2 to 4 conditions. | Game LEVELs; a HUD shows the one variable. | One variable changes per level. | NK cells and MHC-I (Ljunggren and Kärre, 1985). |
| Split screen | One difference between two groups. | Two panels with the same layout, for the whole video. | The same beats in both; only one thing is different. | A normal mouse and a knockout mouse. |
| Inside and outside | A process that crosses a border (a membrane, a wall, the skin). | A cell in section, or a border across the frame. | Molecules and cells cross the border and act on each side. | CDK4 and p16 in the cell cycle. |
| Timeline | A history with dates, or a result that takes years. | A timeline at the bottom with years and a "now" cursor. | Marks appear on their words; the cursor jumps back and forward (<< >>). | Melanoma in a donor kidney, 16 years after the donor was treated (MacKie et al., 2003). |
| Wrong guess | A result against common sense. | The hero and the dish. | The hero bets on the obvious answer. The dish shows the other answer. | Antibiotics do not kill a cold virus. |
| Man in a hole | A discovery that fixes a problem. | A health bar. | The bar falls. A new tool arrives. The bar ends above the start. | Insulin saves a diabetic dog. |
| Detective | An unknown cause found by elimination. | A row of suspect cards. | Each test crosses out one card. | H. pylori causes stomach ulcers. |
| Machine tour | A mechanism with ordered steps. | A belt through numbered stations. | One molecule moves from station to station. | A ribosome makes a protein. |
| Zoom ladder | A scale or a very large number. | A fixed frame and a HUD counter of the scale. | The content zooms 10x a step; a zoom step is not a set change. | Mouse, cell, DNA. |
| Counter race | A rate, a dose, or a growth curve. | Two populations and one timer. | The populations race against the timer. | Bacteria divide every 20 minutes. |
| Time-lapse | A slow change in one subject. | One fixed frame and a day counter. | The subject changes; the counter runs. | A wound heals. |
| Boss fight | An arms race between two agents. | Two characters face to face. | They trade moves; each move gets a name card. | A virus against interferon. |
| Remove a part | A function that is clear only when it is absent. | A normal system. | One part goes away. The system fails. | Mice without leptin get fat. |
