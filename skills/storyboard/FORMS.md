# Forms

Use these forms as ideas, not as templates. Always add one form that is not in this list. Compare it with the best catalogue form. Keep the form with the clearer final frame.

## Rules to select and test a form

1. Write the result as one sentence: "AND ..., BUT ..., THEREFORE ...". If you cannot, do not draw.
2. Make the final frame first. Then select the form that leads to it.
3. Find the one comparison that carries the result. Keep the same position and scale on both sides.
4. Make the result readable with the sound off. Use one caption word or one HUD value.
5. Give the viewer a stake before the result: a guess, a character, or a risk. Show the wrong idea, then break it.

## Catalogue

| Form | Fits | The viewer sees | Example |
|---|---|---|---|
| Levels | An experiment with 2 to 4 conditions. | Game LEVELs. One variable changes per level. A HUD shows that variable. | NK cells and MHC-I (Ljunggren and Kärre, 1985). |
| Split screen | One difference between two groups. | Two panels with the same layout. Only one thing is different. | A normal mouse and a knockout mouse. |
| Wrong guess | A result against common sense. | The hero bets on the obvious answer. The dish shows the other answer. | Antibiotics do not kill a cold virus. |
| Man in a hole | A discovery that fixes a problem. | A health bar falls. A new tool arrives. The bar ends above the start. | Insulin saves a diabetic dog. |
| Detective | An unknown cause found by elimination. | Suspect cards. Each test crosses out one card. | H. pylori causes stomach ulcers. |
| Machine tour | A mechanism with ordered steps. | One molecule moves on a belt through numbered stations. | A ribosome makes a protein. |
| Zoom ladder | A scale or a very large number. | Zoom steps of 10x. A HUD counter shows the scale. | Mouse, cell, DNA. |
| Counter race | A rate, a dose, or a growth curve. | Two populations race against one timer. | Bacteria divide every 20 minutes. |
| Time-lapse | A slow change in one subject. | One fixed frame. A day counter runs. | A wound heals. |
| Boss fight | An arms race between two agents. | Two characters trade moves. Each move gets a name card. | A virus against interferon. |
| Remove a part | A function that is clear only when it is absent. | A normal system. One part goes away. The system fails. | Mice without leptin get fat. |
